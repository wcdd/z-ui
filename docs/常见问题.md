# 常见问题（FAQ）

## 安装相关

### Q：运行脚本提示「请用 root 运行」
A：脚本需要 root 权限来安装程序、写 systemd 服务。请用 `sudo -i` 切到 root，或在命令前加 `sudo`。

### Q：所有下载镜像都失败怎么办？
A：脚本会提示你手动下载并上传：
1. 在能访问 GitHub 的机器上下载对应架构的包（脚本会显示链接）。
2. 用 `scp` 上传到目标机的 `/tmp/realm.tar.gz`。
3. 重新运行安装，脚本会自动识别已存在的包。

### Q：怎么查看自己机器的架构？
A：执行 `uname -m`。`x86_64` 是常见的 64 位 Intel/AMD；`aarch64` 是 ARM64。

## 转发规则相关

### Q：本机端口和目标端口必须一样吗？
A：手动添加时不要求一样，你可以本机监听 `10000` 转发到目标 `443`。但**3x-ui 自动同步**为了对应关系清晰，强制本机端口 = 远端端口。

### Q：添加规则后转发不通？
A：依次排查：
1. 目标 IP、端口是否填对，落地机服务是否正常。
2. 本机防火墙是否放行了监听端口（脚本会自动 `ufw allow`，但若你用的是其它防火墙如 firewalld 或云厂商安全组，需手动放行）。
3. 云服务器还要在**控制台安全组**里放行对应端口。
4. 用菜单 `10` 看 realm 实时日志是否有报错。

### Q：已记忆的 IP 怎么删除？
A：主菜单 `6. 管理已记忆的目标IP` → `2. 删除IP`。

## 3x-ui 同步相关

### Q：同步报 `HTTP 401`
A：表示鉴权失败。检查：
- 3x-ui 版本是否 **≥ 3.2.0**（旧版本的 token 机制不同）。
- API Token 是否复制正确、是否已过期。
- 面板里是否已开启 API token 功能。

### Q：同步报 `HTTP 404` 或「返回非预期内容」
A：多半是**面板地址填错**，特别是漏了 web base path。正确格式：
```
https://你的IP:面板端口/你的路径
例如 https://1.2.3.4:2053/abcdef
```
路径那一段（`abcdef`）是 3x-ui 安装时设置的 base path，不能漏。

### Q：面板用的是自签 SSL 证书，会有问题吗？
A：不会。脚本用 `curl -k` 已忽略证书校验。

### Q：「转发落地 IP」该填什么？
A：填 realm 要把流量转发过去的目标 IP，通常就是**运行这个 3x-ui 面板的服务器的公网 IP**。同步出来的规则会是 `本机端口 → 这个IP:同端口`。

### Q：同步会动我手动加的规则吗？
A：不会。手动规则来源标记是 `manual`，同步只增删自己来源（`sync:监控名`）的规则，互不干扰。

### Q：删除监控目标时，已经同步出来的转发规则会怎样？
A：删除时会问你是否一并删除。选「是」则连带清理；选「否」则保留这些转发规则，只是不再自动维护。

### Q：没有 jq 能正常同步吗？
A：能。脚本会先尝试自动安装 jq；装不上则使用内置的 grep/sed 解析，功能不受影响。jq 只是让解析更稳健。

### Q：轮询间隔设多少合适？
A：默认 60 秒。节点变动不频繁的话可以设大些（如 300 秒）减少请求；需要更快响应可设小，但建议不低于 30 秒，避免给面板太大压力。

## 守护进程相关

### Q：怎么确认后台同步在运行？
A：主菜单顶部会显示「同步守护：● 运行中 / 已停止」。也可在终端执行：
```bash
systemctl status realm-sync
```

### Q：守护进程崩溃了会自动恢复吗？
A：会。服务配置了 `Restart=always`，异常退出 5 秒后自动重启。同时设了重启频率上限，防止极端情况下疯狂重启。

### Q：服务器重启后还会自动同步吗？
A：会。服务已设为开机自启（`systemctl enable`）。

### Q：怎么手动看守护进程的系统日志？
A：
```bash
journalctl -u realm-sync -f
```
而同步的业务日志（新增/删除/失败）在面板 `5 → 5` 查看，或直接看 `/etc/realm/sync.log`。

## 卸载相关

### Q：怎么完全卸载？
A：主菜单 `11. 卸载 realm`，会停止并删除两个服务、删除所有规则与配置，并询问是否移除 `z-ui` 快捷命令。

### Q：卸载会删掉我的转发规则吗？
A：会。卸载是彻底清理，包括 `/etc/realm` 下所有数据。如需保留请提前备份该目录。
